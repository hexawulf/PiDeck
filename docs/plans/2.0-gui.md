# PiDeck 2.0 — GUI refresh plan

Status: PLANNED — CEO review 2026-09-23 (HOLD SCOPE), eng review 2026-09-24 (BIG CHANGE).
Next: implement P1 on `feat/2.0-gui`. **Eng review amendments at the bottom override earlier sections.**
Scope rule: user-facing GUI only. No backend changes (see TODOS.md for deferred backend items).

## Decisions

| # | Decision | Choice |
|---|---|---|
| D1 | Grid engine | `react-grid-layout` 2.x (drag/resize/breakpoints); add up/down/hide buttons for keyboard a11y |
| D2 | Persistence | `localStorage` key `pideck:prefs:v1`, zod-validated, Export/Import JSON in Settings, Reset button |
| D3 | Editing | Locked by default; "Edit layout" toggle; below `md` → single column in saved order, no drag |
| D4 | Quick Actions | Move into command palette; optional small Quick Actions widget; Update System always confirms |
| D5 | Refresh | Global speed multiplier Live x1 / Relaxed x2 / Slow x5 / Paused; each query keeps its base interval |
| D6 | Rollout | Three phases, each on `feat/2.0-gui`, E2E on :5017, tagged + deployed separately |

Made without a question (obvious):
- Tabs become wouter routes `/dashboard /logs /apps /cron /settings` (Express `*` fallback already serves SPA).
- Hidden widgets are unmounted, so their polling stops.
- One "Top Processes" widget fed by `systemInfo.processes`; drop client use of `/api/metrics/top-processes`.
- Delete stub "Thermal & Power" card; register existing unused `ThermalZoneBox`, `PowerStatusBox`.
- Per-widget ErrorBoundary inside `WidgetFrame` (today one throwing widget blanks the app).
- Pause is session-only (not persisted) and always shows a header badge.

## Architecture

```
URL (wouter) ─► AppShell (header, tab <Link>s, ⌘K CommandPalette, Shortcuts)
                   │
      PrefsProvider ◄──── RefreshProvider (paused, speed; useRefetch(tier) → ms | false)
      (layout, hidden, density, pins)
        │ ▲  zod
        ▼ │
      localStorage "pideck:prefs:v1"
                   │
      DashboardGrid (react-grid-layout; locked unless Edit mode)
                   │ for each visible id
      WIDGETS registry {id, title, icon, defaultSize, min/max, component}
                   └─► <WidgetFrame> (chrome, loading/error/empty, ErrorBoundary) ─► <XxxBox/>
                                        │ unchanged REST + react-query
                                   Express /api/* (no changes)
```

Prefs load/save flow:
```
load: localStorage → JSON.parse → zod(PrefsV1) → reconcile(registry) → PrefsProvider
        blocked→defaults  corrupt/invalid→backup to pideck:prefs:v1.bad + defaults
        unknown id→drop   new id→append bottom   hidden id→stay hidden
save: onLayoutChange → debounce 300ms → validate → setItem → 'storage' event syncs other tabs
```

Edit-mode / refresh state:
```
 View ──[Edit layout]──► Editing ──[Done | Esc]──► View        (Editing impossible below md)
 Live x1 ⇄ Relaxed x2 ⇄ Slow x5      any ──[Space | Pause]──► Paused ──[Space | Resume]──► previous
```

## Phases

**P1 — Foundations + visible fixes** (tag `2.0-p1`)
- Routes for tabs; header tabs become links; back button works.
- `WIDGETS` registry, `WidgetFrame`, `useWidgetQuery(key, url, tier)`; extract CPU/Memory/Temp/Network inline cards to `widgets/*Box.tsx`.
- Strip own card chrome from all `*Box` widgets; remove `*-row.tsx` wrappers; consistent size grid.
- Merge duplicate Top Processes; delete stub Thermal & Power; add ThermalZone + PowerStatus widgets.
- Charts: fix Y-axis (drop `left:-20` margin, unit in axis label not every tick, formatted ticks), time-range picker 15m/1h/6h/24h (client-side filter), `downsample()` to ≤300 points.
- Per-widget ErrorBoundary.

**P2 — Layout + density + refresh** (tag `2.0-p2`)
- react-grid-layout grid, Edit mode, hide/show list, Reset layout.
- `pideck:prefs:v1` load/save/reconcile, Export/Import in Settings (64KB cap, zod `.strict()`).
- Dense mode via `data-density` attribute + tokens.
- RefreshProvider + `useRefetch(tier)` replacing 15 hard-coded `refetchInterval`s; header speed/pause control.

**P3 — Power-user features** (tag `2.0-p3`)
- Command palette (lazy-loaded, Radix Dialog): navigate, toggle theme/density/edit, pause, refresh, Update System (confirm), open log.
- Keyboard shortcuts (`?` help sheet); single keys inactive in inputs; nothing destructive on a single key.
- Log pins + saved filters via `useLogPins()` hook (not inline in the 649-line log-viewer); stale pins greyed.
- About modal Diagnostics line (version, prefs version, visible widgets, refresh state, last prefs reset reason).

## Error & rescue registry

| Codepath | Failure | Rescue | User sees |
|---|---|---|---|
| loadPrefs | storage blocked (SecurityError) | in-memory defaults | toast once "Layout can't be saved in this browser" |
| loadPrefs | corrupt JSON / ZodError / old version | backup `.bad`, defaults | toast "Saved layout was invalid – reset to default" |
| savePrefs | QuotaExceededError | keep in memory | toast "Couldn't save layout" |
| importPrefs | not JSON / >64KB / schema | reject, keep current | inline error with zod path |
| Widget render | TypeError etc. | ErrorBoundary + console.error("[widget:id]") | that card: "Widget failed – Retry" |
| Layout reconcile | orphan/new id | drop / append | nothing |
| Palette Update System | POST fails / CSRF | existing toast | "Failed to update system" |
| Pinned log | file gone (404) | mark stale | greyed pin "file no longer available" |

Failure modes with RESCUED=N & silent: **none** after this plan.

## Tests

`downsample` (0/1/299/300/17280, keeps endpoints); `useRefetch` (x1/x2/x5/paused→false);

`/logs` deep link + back; corrupt localStorage → dashboard renders; all widget endpoints 500 → every card shows error, shell works;
axe 0 serious in view + edit, light + dark.
Flakiness: drag via handles/keyboard, not pixel offsets.

## Deploy / rollback

- Work on `feat/2.0-gui`; never `npm run build` on main mid-work (it deploys live — pm2 serves dist/).
- Before each phase merge: tag main `pre-2.0-gui-pN`, `npm audit`, unit + E2E green.
- Rollback: `git checkout <tag> && npm run build && pm2 reload pideck` (~2 min, no data migration).
- Post-deploy: load pideck.piapps.dev, check console clean, CSP no violations, drag/reload, logs deep link.

## Update 2026-09-27 — server-side sampler landed (branch `fix/sampler-and-log-safety`)

The server now samples every 60s (`server/services/sampler.ts`): it writes the history row and
evaluates the temperature alert itself, and `/api/system/info` is read-only.

- **E1:** `AlertHeartbeat` is no longer needed for alerts — they are evaluated on the server whether
  or not anyone polls. What remains of E1 is that `useAlerts` (`/api/system/alerts`) keeps polling
  while paused, so toasts still appear. P2 scope is otherwise unchanged.
- **E19:** history is continuous now; gaps mean the server was down. The chart caption says so.
  `downsample()` gap handling stays.
- TODOS 1 (sampler), grep injection and hostLogs ReDoS are done and removed from TODOS.md.
